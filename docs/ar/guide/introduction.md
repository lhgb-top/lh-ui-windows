# مقدمة

**lh-ui-windows** هو تنفيذ طرف Windows لـ **سلالة أصلية** من عائلة lh-ui: مكتبة مكوّنات واجهة مبنية على **C# + WinUI 3** (.NET 8، Windows App SDK).

## موقعها داخل العائلة

```
                        ┌── سلالة الويب: share (TS core + SCSS) → plus / vue2 / react / uniapp
عائلة lh-ui (علامة واحدة)├──
                        └── سلالة أصلية: core (رموز JSON + عقود + codegen) → android / ios / harmony / windows
                                                                    ↑ هذا المستودع
```

- **مركز وقت البناء**: `lh-ui-core` هو المصدر الأصلي للرموز في السلالة الأصلية (`tokens/*.json`)، وعقود المكوّنات (`specs/`)، والحالات الذهبية (`cases/`)، وأدوات codegen. يولّد هياكل رموز C# (`LhTokens` / `LhDarkTokens` / `LhShadow` / `LhEasing`)، **ولا يولّد أي تنفيذ للمكوّنات**.
- **مسؤولية هذا المستودع**: كتابة مكوّنات WinUI 3 يدويًا، ودمج السمات (`LhTheme.Apply` + حدث `ThemeChanged`)، وربط تعدادات الخصائص بالقيم الافتراضية، وترجمة الحالات الذهبية إلى اختبارات xUnit.
- **استقلال عن سلالة الويب**: لا يعتمد على `@lh-ui/share`، ولا يفرض الطرفان أي ترتيب إصدار على الآخر. يتم الحفاظ على الاتساق البصري عبر المطابقة اليدوية مع *خط أساس لغة التصميم*.

> **التاريخ**: حلّ هذا المستودع في 2026-10-12 محل `lh-ui-c` السابق (طرف C/C++ المضمّن) — فأصبح العضو الرابع في السلالة الأصلية طرف سطح مكتب Windows بدلًا من الطرف المضمّن (الخطة الرئيسية D10).

## لغة التصميم

سمة النمط الصيني: لون رئيسي 青花瓷 (الخزف الأزرق) (`#2B4C7C`)، خلفية 宣纸白 (أبيض ورق الأرز) (`#FAF6F0`)، 松花绿 (أخضر الصنوبر) للنجاح، 藤黄 (أصفر عشبي) للتحذير، 朱砂 (زنجفر) للخطر، مع حزمة خطوط مذيّلة (Noto Serif SC → STSong → SimSun). كل قيمة بصرية هي رمز، ولا تظهر أي قيمة حرفية داخل المكوّنات. وفي التعبير البصري يُختم العمل بقама هندسية معتدلة على طراز Fluent (تسلسل نصف قطر الزاوية وحدود رفيعة مدفوعة بالرموز).

## لماذا WinUI 3

- واجهة توضيحية حديثة من Windows App SDK، وتتطابق ذهنيًا مع Compose / SwiftUI / ArkUI، مما يسهّل مطابقة العقود عبر الأطراف.
- لا يوجد وقت تشغيل للويب ولا جسر HTML/CSS، أداء أصلي خالص.
- التوزيع عبر NuGet (بعد إتمام nM6)، وتكامل بنقرة واحدة ضمن منظومة .NET.

## الحالة الحالية

- **جميع مكوّنات P0 الخمسة عشر مسلّمة** (استهلاك الرموز + تحليل المظهر بدوال نقية + عناصر تحكم WinUI 3 + حالات xUnit الذهبية + تطبيق عرض توضيحي + موقع توثيق): button / icon / tag / cell / text / input / textarea / checkbox / radio / switch / picker / dialog / toast / loading / navbar
