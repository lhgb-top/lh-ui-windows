features:
  - title: Token-driven
    details: Components contain zero hardcoded colors or spacing — they all consume the LhTokens / LhDarkTokens generated by core codegen, so changing a token takes effect across the whole app instantly.
  - title: Spec-aligned
    details: Prop names line up verbatim with lh-ui-core/specs, sharing behavior with the Android / iOS / HarmonyOS ends and the web bloodline.
  - title: Golden-case guarded
    details: The behavioral assertions from cases/*.json are translated into xUnit tests — dotnet test runs the full regression in one step.
  - title: Light & dark themes
    details: LhTheme.Apply toggles in one line (static palettes + a ThemeChanged hot repaint); dark tokens are pre-computed by core — no runtime color mixing.
  - title: Chinese-style design language
    details: 青花瓷 (ceramic blue) primary, 宣纸白 (rice-paper white) background, 藤黄 (gamboge) and 朱砂 (cinnabar) accents, a serif font stack — same source, same values as the web bloodline.
  - title: Native WinUI 3
    details: Hand-written pure C# + WinUI 3 UI, no JS web runtime — a first-class citizen of the Fluent design system.
