# Установка

## Требования к окружению

- .NET 8 SDK (целевой фреймворк `net8.0-windows10.0.19041.0`)
- Windows App SDK 1.6+ (Windows 10 1809+ или Windows 11)
- Инструменты сборки: Node.js >= 20 + pnpm (используются только для линковки токенов и сайта документации, **в рантайм не попадают**)

## Подключение через NuGet (после запуска цепочки публикации nM6)

```bash
dotnet add package LhUi.Windows
```

```xml
<ItemGroup>
  <PackageReference Include="LhUi.Windows" Version="0.0.1" />
</ItemGroup>
```

## Интеграция из исходников (текущий этап)

При семейной раскладке подключайтесь напрямую к библиотеке классов этого репозитория (решение содержит библиотеку `src/LhUi.csproj` + тесты `tests/` + демо-приложение `demo/`):

```
lh-ui-windows/
├── src/                  # библиотека LhUi (Components/ + Common/ + Tokens/)
├── tests/                # золотые сценарии xUnit
├── demo/                 # демо-приложение (все варианты + переключение светлой/тёмной темы)
└── docs/                 # сайт документации VitePress
```

## Синхронизация токенов

Токены — генерируемый артефакт, их необходимо синхронизировать из `lh-ui-core` (единый источник, ручное редактирование запрещено):

```bash
cd ../lh-ui-core && pnpm codegen   # сгенерировать артефакты токенов dist/windows
cd ../lh-ui-windows
pnpm install                        # установить инструменты сборки
pnpm link:tokens                    # синхронизировать токены в src/Tokens/
```

`pnpm link:tokens` имеет трёхуровневую защиту наличия: локальный `../lh-ui-core/dist/windows` → npm-артефакт `@lh-ui/core` → ошибка.

## Проверка установки

```bash
dotnet build     # сборка LhUi / LhUi.Tests / LhUi.Demo (включая проверку типов C#)
dotnet test      # золотые сценарии xUnit (15 шт., утверждают внешний вид через чистые функции Resolve)
```
