# Введение

**lh-ui-windows** — реализация Windows-стороны **нативного направления** семейства lh-ui: библиотека UI-компонентов на **C# + WinUI 3** (.NET 8, Windows App SDK).

## Место в семействе

```
                        ┌── направление web: share (TS core + SCSS) → plus / vue2 / react / uniapp
семейство lh-ui ────────┤
(один бренд)            └── направление native: core (JSON-токены + контракты + codegen) → android / ios / harmony / windows
                                                                    ↑ этот репозиторий
```

- **Центр сборки**: `lh-ui-core` — единый источник токенов нативного направления (`tokens/*.json`), компонентные контракты (`specs/`), золотые сценарии (`cases/`) и инструменты codegen. Он генерирует каркасы токенов на C# (`LhTokens` / `LhDarkTokens` / `LhShadow` / `LhEasing`) и **не генерирует никаких реализаций компонентов**.
- **Задачи этого репозитория**: написанные вручную компоненты WinUI 3, подключение тем (`LhTheme.Apply` + событие `ThemeChanged`), привязка свойств-перечислений и значений по умолчанию, перевод золотых сценариев в тесты xUnit.
- **Независимость от направления web**: нет зависимости от `@lh-ui/share`, релизы не влияют друг на друга. Визуальная согласованность поддерживается вручную согласно *Базовому стандарту языка дизайна*.

> **История**: этот репозиторий 2026-10-12 заменил прежний `lh-ui-c` (встроенная C/C++-сторона) — четвёртым членом нативного направления вместо встроенной стороны стала настольная Windows (генеральный план, решение D10).

## Язык дизайна

Тема в китайском стиле: основной цвет 青花瓷 (сине-белый фарфор) (`#2B4C7C`), фон 宣纸白 (рисово-бумажный белый) (`#FAF6F0`), успех — 松花绿 (зелёный сосны), предупреждение — 藤黄 (gamboge), опасность — 朱砂 (киноварь); стек серифных шрифтов (Noto Serif SC → STSong → SimSun). Все визуальные значения являются токенами, в компонентах нет ни одного литерала. Визуальное выражение сдерживается геометрией Fluent (токен-ориентированная иерархия скруглений и тонкие границы).

## Почему WinUI 3

- Современный декларативный UI Windows App SDK, ментально однороден с Compose / SwiftUI / ArkUI — легко выровнять кроссплатформенные контракты
- Никакого web-рантайма, никакого HTML/CSS-моста — нативная производительность
- Распространение через NuGet (после решения nM6), одномоментная интеграция в экосистему .NET
