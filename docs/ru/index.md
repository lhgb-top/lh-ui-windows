features:
  - title: Токен-ориентированность
    details: В компонентах нет жёстко заданных цветов и отступов — все они используют LhTokens / LhDarkTokens, сгенерированные codegen'ом core, поэтому изменение токена мгновенно применяется ко всему приложению.
  - title: Согласованность с контрактами
    details: Имена свойств дословно соответствуют lh-ui-core/specs, а поведение — Android / iOS / HarmonyOS-сторонам и направлению web.
  - title: Защита золотыми сценариями
    details: Поведенческие утверждения из cases/*.json переведены в тесты xUnit — dotnet test выполняет полную регрессию одним шагом.
  - title: Светлая и тёмная темы
    details: LhTheme.Apply переключает одним вызовом (статические палитры + горячая перерисовка через событие ThemeChanged); тёмные токены предвычислены в core — никакого смешивания цветов в рантайме.
  - title: Язык дизайна в китайском стиле
    details: Основной цвет 青花瓷 (сине-белый фарфор), фон 宣纸白 (рисово-бумажный белый), акценты 藤黄 (gamboge) и 朱砂 (киноварь), стек серифных шрифтов — тот же источник и те же значения, что у направления web.
  - title: Родной WinUI 3
    details: UI, написанный вручную на чистом C# + WinUI 3, без web-рантайма на JS — полноправный гражданин дизайн-системы Fluent.
